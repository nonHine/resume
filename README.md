## 🚀 3 ผลงานเด่น (Selected Projects)

### 01. [Larb Raek Phob Tickets](https://github.com/nonHine/larb-raek-phob-tickets) — Lead Full-Stack & AI System Developer
- **Stack:** `Next.js` · `TypeScript` · `Supabase (PostgreSQL)` · `AI Slip OCR` · `PromptPay Dynamic QR`
- **Impact:** 
  - ร่วมมือกับนักศึกษาคณะบริหารธุรกิจและการบัญชี (KKBS) พัฒนาระบบจำหน่ายตั๋วอีเวนต์แบบ Full-Stack พร้อมระบบสร้าง PromptPay Dynamic QR และอัปเดตสถานะคำสั่งซื้อแบบ Real-time
  - บูรณาการ **AI Computer Vision (OCR)** ตรวจสอบสลิปโอนเงินอัตโนมัติ ลดเวลาตรวจสอบลง 100% พร้อมป้องกันสลิปซ้ำแม่นยำ
  - ระบบสแกนตั๋ว QR Code สำหรับจุดลงทะเบียนหน้างานจริง รองรับการเช็กอินผู้เข้าร่วมงานกว่า **350+ คน** ได้อย่างรวดเร็ว

### 02. ROADMAP.STUDIO — Interactive Learning Web Developer
- **Stack:** `JavaScript ES6+` · `Offline-Ready PWA` · `Web Audio API` · `CEFR B2 Hub` · `Tailwind CSS`
- **Impact:** 
  - พัฒนาเว็บแอปพลิเคชันศูนย์การเรียนรู้และจำลองการสอบ 100 ข้อ Interactive พร้อมระบบตรวจคำตอบ วิเคราะห์จุดแข็ง-จุดอ่อน และแสดงสถิติคะแนนทันที (Instant Feedback)
  - ออกแบบสถาปัตยกรรม **Offline-Ready 100%** ร่วมกับ **Web Audio API** ช่วยให้เข้าถึงสื่อการเรียนรู้ได้โดยไม่ต้องพึ่งพาอินเทอร์เน็ต
  - คะแนนประสิทธิภาพ **Lighthouse สูงกว่า 95 คะแนน** และนำไปใช้เป็นเว็บติวออนไลน์ส่งให้เพื่อนนักศึกษาใช้งานติวเนื้อหาจริง ช่วยยกระดับผลคะแนนสอบให้สูงขึ้น

### 03. AI for Editor & Motion Animation — Creative Video & AI Workflow Specialist
- **Stack:** `CapCut` · `DaVinci Resolve` · `Motion Control AI` · `Prompt-to-Video` · `Audio Waveform Sync`
- **Impact:** 
  - ประยุกต์ใช้ **CapCut** และ **DaVinci Resolve** ร่วมกับโมเดล Generative AI (Prompt-to-Video & Motion Control) สร้างสรรค์โมชันกราฟิกและวิดีโอคอนเทนต์ระดับโปรดักชัน
  - พัฒนา Automated AI Workflow สำหรับการวาง Storyboard, สร้าง Key Visuals และตัดต่อเสียง/ภาพแบบ Synchronization **ลดระยะเวลาการผลิตสื่อลงกว่า 80%**
  - ผลิตสื่อดิจิทัลและ Visual Assets คุณภาพสูง เพิ่มยอด Engagement และความน่าสนใจของคอนเทนต์อย่างมีนัยสำคัญ
