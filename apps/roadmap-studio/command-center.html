CRITICAL SYNTAX PROCESSES // 3 FATAL EXAM TRAPS

3 กับดักตัวหลอกที่นักศึกษาเสียคะแนนมากที่สุด
และวิธีเช็กเงื่อนไขตัดช้อยส์ใน 3 วินาที

ข้อสอบพาร์ต Grammar และ Conversation มักวางตัวหลอกซ้ำจุดเดิมทุกปี จำแค่ 3 กฎเปรียบเทียบนี้ คุณจะไม่ตกหลุมพรางของคนออกข้อสอบ อีกต่อไป

TRAP #01 // CONDITIONALS

ห้ามใส่ปฏิเสธซ้อนหลัง unless เด็ดขาด!

เพราะ unless แปลว่า "ถ้า...ไม่ (if not)" อยู่แล้ว โจทย์จึงชอบหลอกด้วยการใส่ don't / doesn't ตามหลัง และระวังความต่างระหว่าง in case กับ in case of

❌ unless she doesn't ask
✅ unless she asks (บอกเล่า)
• in case + S + V (ประโยค)
• in case of + Noun (คำนาม)
เจาะลึกใน Lesson 01 →
TRAP #02 // PREFERENCES

แยกให้ขาด: 'd rather vs 'd prefer vs prefer

ตัวหลอกยอดฮิตอันดับ 1 ของ Unit 3 คือการสลับคำเชื่อม to และ than หรือแอบเติม to หลัง would rather!

✅ 'd rather + V.inf (ห้ามมี to!)
  I'd rather stay than go.
✅ 'd rather NOT + V.inf
✅ 'd prefer + TO V.inf
✅ prefer V-ing TO V-ing
ดูตารางเทียบใน Cheatsheet →
TRAP #03 // WORD ORDER

คำถามทางอ้อม Indirect Qs ต้องเรียงแบบ บอกเล่า!

เมื่อขึ้นต้นด้วย Could you tell me... หรือ Do you know... ข้างหลังต้องเรียง Subject + Verb ห้ามมี do / does / did มาคั่นหน้าประธานเด็ดขาด!

❌ ...where did you spend?
✅ ...where you spent (S + V2)
• Yes/No ใช้ if หรือ whether:
✅ Do you know if she plays...?

EXAM BLUEPRINT // UNIT 4 PAST PLANS & INDIRECT Q

Wall of Golden Rules:
6 กฎเหล็กที่ต้องจำให้ขึ้นใจก่อนเปิดกระดาษคำถาม

สรุปกฎสั้นกระชับที่ช่วยตัดช้อยส์หลอกได้ทันทีในพาร์ต Grammar, Vocabulary, Conversation และ Seen Reading

Conditionals Golden Rule UNIT 3A // Q21–25

“เจอ 'd rather ตามด้วยกริยาช่อง 1 เพียวๆ ห้ามมี to (เช่น I'd rather stay หรือปฏิเสธ 'd rather not stay) แต่ถ้าเจอ 'd prefer ต้องมี to + V.inf เสมอ!”

R2
Preferences Syntax Lock UNIT 3D // Q26–30 & CONVO

“ถ้าประธานเป็นสิ่งของที่ไม่สามารถทำเองได้ เช่น The kitchen / The salad ต้องใช้โครงสร้างถูกกระทำ needs to be + V.3 (เช่น needs to be cleaned / washed)”

R3
Passive Modals Rule UNIT 3B // OBLIGATION

“เมื่อประโยคมีคำว่า ...but I forgot / ...but it was closed ให้มองหาโครงสร้างแผนในอดีตที่ไม่สำเร็จทันที: was/were going to + V.inf หรือ meant to + V.inf”

R4
Unfulfilled Past Plans UNIT 4A // Q31–35

“หลังวลีนำคำถามทางอ้อม Could you tell me / Do you know / Can I ask ต้องเรียง ประธาน + กริยาแท้ (S + V) เสมอ ห้ามมีกริยาช่วย do / does / did มาคั่นหน้าประธาน!”

R5
Indirect Question Order UNIT 4B // Q36–40
