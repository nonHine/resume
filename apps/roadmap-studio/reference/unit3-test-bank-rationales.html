Unit 3 Master Test Bank & Rationales

เฉลยละเอียดและวิเคราะห์เหตุผลครบ 100% ทุกข้อ: Unit 3 Test A/B และ Quick Quiz A/B

📘 1. Unit 3 Test — Version A (ข้อสอบฉบับเต็มและเฉลยทางการ)

Exercise 1: Sentence Transformation (Conditionals 1–7)

ข้อโจทย์เดิมเฉลยทางการคำอธิบายเหตุผล
1You need to clean your room or you're not going to the cinema.Unless you cleanunless = if not แปลงรูปปฏิเสธ "or you're not..." ให้เป็น unless + บอกเล่า
2You should take some water because you might get thirsty.in case you getin case + S + V เตรียมการเผื่อหิวน้ำ
3It might rain this afternoon, but we're still going for a walk.even if it rainseven if ต่อให้ฝนตกก็จะไปเดินเล่น (ผลลัพธ์ไม่เปลี่ยน)
4Don't say anything to Rosie about the party if she doesn't ask you.unless she asksunless แทน if she doesn't ask (she asks เติม s)
5The airport will close if the weather is bad.In case of bad weatherIn case of + Noun phrase ในกรณีฉุกเฉิน/ทางการ
6They need to catch the first train or they won't arrive.unless they catchจะไม่ทันเวลา เว้นแต่จะขึ้นรถไฟขบวนแรก
7I don't know the answer and I wouldn't tell you it anyway.Even if I knewสมมุติขัดแย้งปัจจุบัน: Even if + Past Simple (knew) คู่กับ wouldn't tell

Exercise 2: Modals of Obligation, Necessity & Permission (1–7)

1. permitted (ผู้โดยสารได้รับอนุญาต) 2. essential (จำเป็นอย่างยิ่ง) 3. supposed (คาดหมายให้ปิดฮีตเตอร์) 4. need (จำเป็นต้องหาแว่น) 5. not allowed (ห้ามดูโน้ตระหว่างสอบ) 6. needs (สลัดต้องได้รับการล้าง - needs to be washed) 7. got (I've got to leave = have to)

Exercise 3: Preferences (1–6)

1. rather (would rather + bare inf) 2. reading (prefer reading to watching) 3. Would (Would you prefer to) 4. definitely prefer (เน้นย้ำความชอบ) 5. have (I'd rather have) 6. to be (would prefer to be)

Exercise 4: Vocabulary Collocations Matching (1–8)

1.g (meet the deadline) 2.b (keep to a routine) 3.d (fall behind schedule) 4.e (lose concentration) 5.a (get something out of the way) 6.f (deal with a challenge) 7.h (manage a team) 8.c (take responsibility)

Exercise 5: Work Vocabulary Word Completion (1–12)

1. temporary 2. organise 3. background 4. charge (in charge of) 5. opportunities 6. exploited 7. long-term 8. handle 9. unfairly 10. experience 11. permanent 12. deal (deal with)

📗 2. Unit 3 Test — Version B (ข้อสอบฉบับคู่ขนานและเฉลยทางการ)

Exercise 1: Conditionals Transformation (1–7)

ข้อโจทย์เดิมเฉลยทางการคำอธิบายเหตุผล
1You should write your name on your jacket because you might lose it.in case you losein case + S + V เผื่อทำเสื้อหาย
2They might offer us a nicer room, but we’re still not staying in this hotel.even if they offereven if ต่อให้เสนอห้องที่ดีกว่าก็จะไม่พัก
3You need to apologise for being rude to me or I’m not going to help you.unless you apologiseunless + บอกเล่า (เว้นแต่จะขอโทษ)
4You should press this button to speak to the driver if there is an emergency.In case of emergencyIn case of + Noun
5Don’t make Naim get up if he doesn't want to.unless he wantsunless + he wants (แทน if he doesn't want)
6You won’t pass the exam if you don't work hard.unless you workunless you work hard
7We don’t have a car, but we wouldn’t have anywhere to park it anyway.Even if we hadสมมุติในอดีต: Even if we had a car

Exercise 2: Modals (1–7)

1. supposed 2. permitted 3. needs (The salad needs to be washed) 4. got (I've got to send) 5. essential 6. not allowed (not allowed to drive) 7. need

Exercise 3: Preferences (1–6)

1. prefer (Would you prefer to stay in) 2. much rather (I'd much rather eat sushi than pasta) 3. rather not (She'd rather not speak) 4. 'd go for (Given the choice, I'd go for...) 5. Would (Would you prefer) 6. be (would rather be)

Exercise 5: Vocabulary Completion (1–12)

1. exploited 2. background 3. deal 4. experience 5. temporary 6. handle 7. unfairly 8. charge 9. long-term 10. chances 11. organise 12. permanent
